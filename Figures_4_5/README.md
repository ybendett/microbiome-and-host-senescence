# Reproducing Figures 4, 5, and S1

This repository contains the Python script used to reproduce the multiple-age-class simulation figures for the manuscript **The evolution of longevity from the microbiome perspective**.

The main script is:

```text
microbiome_senescence_model_130826.py
```

It reproduces:

- **Figure 4** — multiple-age-class simulations under a host reproductive cost, using empirical life-history schedules for guppies and yellow baboons.
- **Figure 5** — multiple-age-class simulations under a microbial transmission cost and contrasting vertical-transmission regimes.
- **Figure S1** — supplementary robustness analysis analogous to Figure 5, but with microbe A modifying the Gompertz mortality parameter **G** rather than the senescence-rate parameter **R**, and with the maximum relative mortality benefit limited to **0.95**.

The simulation framework uses age-structured host populations carrying either microbe A, which slows host senescence, or microbe B, which does not modify senescence. The code implements horizontal microbial transmission, host reproduction, vertical transmission, mortality, aging, and density-dependent recruitment.

## Requirements

The script was developed and tested for **Python 3.14**.

Install the required Python packages with:


The `xlrd` package is required because the empirical life-history data are distributed as a legacy `.xls` workbook.

## Running the script

Run:

```bash
python microbiome_senescence_model_130826.py
```

The script loads the empirical life-history data, constructs the model parameter sets for guppies and baboons, runs the heatmap simulations, generates the three manuscript figures, and displays them using Matplotlib.

The final section of the script calls:

```python
figures = create_manuscript_figures(
    life_tables=life_tables,
    p_guppy=guppy_params,
    p_baboon=baboon_params,
    res=20,
    steps=500,
    show=True,
)
```

The returned dictionary contains:

```python
figures["fig_1"]
figures["fig_2"]
figures["fig_s1"]
```

The local names `fig_1`, `fig_2`, and `fig_s1` refer to the three figure objects generated by the script. For the manuscript, these correspond to **Figure 4, Figure 5, and Figure S1**, respectively.

## Figure 4

Figure 4 reproduces the multiple-age-class analysis in which the senescence-slowing microbe A pays a cost through **reduced host reproduction** while horizontal transmission is symmetric.

The configuration used by `create_manuscript_figures()` is:

- Gompertz–Makeham parameter modified by A: **R**.
- Maximum relative mortality benefit: **1.0**.
- Symmetric transmission: `T_A = T_B = T`.
- Relative reproductive cost: `alpha_A / alpha_B = 0.65`.
- Baseline age classes for the two simulation panels: **2** and **12**.
- Additional age classes are automatically added when required to cover the longer lifespan of A hosts, until survival falls below `0.0001`.
- Guppy and yellow-baboon life histories are parameterized from fits to the Jones et al. (2014) data.

The resulting six-panel figure contains two heatmaps for each species plus the empirical life-history fitting panel.

## Figure 5

Figure 5 reproduces the multiple-age-class analysis in which microbe A pays a cost through **reduced horizontal transmission** rather than reduced host reproduction.

The three columns compare:

```text
2 age classes, v = 0
2 age classes, v = 1
12 age classes, v = 1
```

where `v` is the probability of vertical microbial transmission.

The heatmap axes are:

- **x-axis:** horizontal transmission ratio `T_A / T_B`.
- **y-axis:** relative decrease in senescence rate, `1 - R_A / R_B`.
- **colour:** equilibrium frequency of hosts carrying microbe A.
- **grey region:** both fixation states are stable and the outcome depends on initial conditions.

For Figure 5, the model uses:

```python
mortality_parameter = "R"
mortality_benefit_max = 1.0
T_ratio = True
exclude = "m"
```

## Figure S1

Figure S1 is the supplementary robustness analysis corresponding to Figure 5, but with microbe A altering the **Gompertz mortality-scale parameter G** instead of the senescence-rate parameter R.

The configuration is:

```python
mortality_parameter = "G"
mortality_benefit_max = 0.95
T_ratio = True
exclude = "m"
```

The heatmap y-axis therefore represents:

```text
1 - G_A / G_B
```

The upper limit is set to **0.95** rather than 1.0 so that `G_A` remains positive and the adaptive age-grid calculation does not produce excessively long death horizons as `G_A` approaches zero.

Otherwise, Figure S1 uses the same panel structure as Figure 5:

```text
2 age classes, v = 0
2 age classes, v = 1
12 age classes, v = 1
```

for both guppies and yellow baboons.

## Important model settings

Several settings in the script determine the exact numerical results.

### Simulation resolution

The manuscript figure reproduction call uses:

```python
res = 20
steps = 500
```

`res=20` creates a 21 × 21 parameter grid for each heatmap.

`steps=500` determines the duration of the full coexistence simulation after reciprocal invasion tests.

### Invasion procedure

Each strain is introduced at:

```python
invasion_p = 0.01
```

and tested for:

```python
invasion_steps = 100
```

The model performs reciprocal invasion tests: rare A into common B and rare B into common A.

The resulting states are interpreted as:

- A cannot invade, B can invade → B fixation.
- A can invade, B cannot invade → A fixation.
- Both can invade → stable polymorphism or a coexistence equilibrium is estimated by the full simulation.
- Neither invasion is successful → the parameter combination is treated as a bistable/non-invasion region and displayed as grey in the heatmaps.

### Adaptive age grid

The discrete age structure is derived from the continuous Gompertz–Makeham survival function.

The effective maximum age is the age at which survival reaches:

```text
ACC = 0.0001
```

The baseline age-class width is determined from the mortality-neutral microbe B population, and additional age classes are added as necessary so that the longer-lived A population is represented.

This is important for reproducing the manuscript figures because the number of interaction opportunities changes with the effective lifespan.

## Empirical life-history fitting

The script fits continuous-time functions to the Jones et al. (2014) data before running the simulations.

### Mortality

Mortality is fitted with the Gompertz–Makeham function:

```text
mu(x) = G exp(R x) + M
```

where:

- `R` controls the age dependence / senescence rate.
- `G` scales the age-dependent mortality component.
- `M` is the age-independent Makeham component.

The corresponding survival function is calculated from the cumulative hazard.

### Reproduction

Age-specific reproduction is fitted with the Gamma-type function:

```text
m(x) = alpha x^beta exp(-gamma x)
```

The fitted functions are then used to construct the age-specific reproduction and survival schedules used by the Leslie matrix.

## Reproducing the figures in a Python session

The script can also be imported and the figure-generation function called explicitly.

For example:

```python
import microbiome_senescence_model_130826 as msm

figures = msm.create_manuscript_figures(
    life_tables=msm.life_tables,
    p_guppy=msm.guppy_params,
    p_baboon=msm.baboon_params,
    res=20,
    steps=500,
    show=True,
)
```

The figure objects can then be saved manually, for example:

```python
figures["fig_1"].savefig("Figure4.png", dpi=300, bbox_inches="tight")
figures["fig_2"].savefig("Figure5.png", dpi=300, bbox_inches="tight")
figures["fig_s1"].savefig("FigureS1.png", dpi=300, bbox_inches="tight")
```

For publication-quality vector output, PDF or SVG can be used instead of PNG.

## Determinism and reproducibility

The model uses no random-number generator in the supplied implementation. The simulations are therefore deterministic for a fixed Python/software environment and identical input files.

For an archival reproduction package, preserve:

1. the exact Python version;
2. package versions;
3. the Jones et al. (2014) `.xls` workbook;
4. the two SVG files;
5. the exact manuscript script;
6. the simulation settings `res=20` and `steps=500`.

Do not modify the fitted-life-history data, parameter sets, or figure-specific settings if the goal is to reproduce the manuscript results exactly.

## Troubleshooting

### `FileNotFoundError` for the `.xls` file

Make sure:

```text
41586_2014_BFnature12789_MOESM42_ESM.xls
```

is in the same directory as the script, or edit:

```python
path = r"41586_2014_BFnature12789_MOESM42_ESM.xls"
```

to point to the file's location.

### `ImportError: No module named svgpath2mpl`

Install:

```bash
pip install svgpath2mpl
```

### Error reading the `.xls` workbook

Install the legacy Excel reader:

```bash
pip install xlrd
```

### Animal icons are missing

Check that the two SVG files are present and that the paths supplied to `add_guppy_icon()` and `add_baboon_icon()` are correct.

The icons are graphical annotations only; a missing icon does not change the numerical model, but the resulting figure will not visually match the manuscript.

### Simulation is slow

The supplied manuscript settings use a 21 × 21 grid and two reciprocal invasion simulations for every grid point and panel. Reproducing all three figures can therefore take several minutes depending on the computer.

For a quick test of the installation, temporarily reduce:

```python
res = 5
steps = 50
```

but restore `res=20` and `steps=500` for manuscript reproduction.

## Scientific correspondence

The script implements the multiple-age-class model described in the manuscript Methods section. In particular, it uses:

- Gompertz–Makeham mortality;
- Gamma-type age-specific reproduction;
- adaptive age-class construction based on a survival threshold of `0.0001`;
- horizontal microbial transmission during host interactions;
- vertical transmission probability `v`;
- density-dependent recruitment;
- reciprocal invasion analysis;
- equilibrium frequency of hosts carrying microbe A as the heatmap response.

The manuscript describes the corresponding analyses as the multiple-age-class simulations under host reproductive costs and microbial transmission costs, with the supplementary analysis extending the mortality effect beyond the direct R-based senescence-rate manipulation.
