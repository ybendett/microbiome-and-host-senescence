# Figure Reproduction

This repository contains the code and data required to reproduce the figures presented in the paper.

The reproduction materials are organized into two independent directories:

- `Figures_2_3/` — code and data for reproducing Figures 2 and 3.
- `Figures_4_5/` — code and data for reproducing Figures 4 and 5.

Each directory contains its own README with instructions and computational details.
